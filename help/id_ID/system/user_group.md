### Kelompok Pengguna
<hr>
Merupakan fasilitas untuk mendefinisikan Groups dari User. Dalam User Groups ini anda bisa membuat pengelompokan User-user system anda serta memberikan hak baca (Read) atau tulis (Write) pada modul-modul Kutubkhanah. Setiap User pada Kutubkhanah bisa bergabung ke lebih dari satu grup.
