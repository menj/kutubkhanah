####Import Item
<hr>
Item import digunakan untuk memasukkan data item ke database Kutubkhanah. Jika kegiatan ini dilakukan dari database Kutubkhanah yang satu ke Kutubkhanah yang lain, maka item import dilakukan setelah bibliography import. Artinya item akan menyesuaikan data bibliografi yang telah diimport lebih dahulu.
